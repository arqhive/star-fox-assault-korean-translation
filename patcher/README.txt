스타폭스 어설트 한글 패치 v1.2f (GameCube)
=============================================

일본판 스타폭스 어설트 이미지에 적용하는 한글 패치입니다. 최종판입니다.
게임 데이터는 들어 있지 않으며, 직접 소유한 디스크에서 만든 이미지가 필요합니다.


[사용법]

  1. 이 폴더에 원본 이미지를 넣고 「패치하기.bat」을 더블클릭합니다.
     또는 원본 이미지 파일을 「패치하기.bat」 위에 끌어다 놓습니다.
  2. 끝나면 원본과 같은 폴더에 「Star Fox Assault (Korean).iso」가 생깁니다.
     원본 파일은 그대로 남습니다.

  처음 실행할 때 Windows가 경고하면 「추가 정보 → 실행」을 누르세요.
  Windows 10 이상에 기본으로 들어 있는 PowerShell을 사용합니다.
  원본 크기만큼(약 1.4GB) 빈 공간이 필요합니다.

  결과 파일 이름을 바꾸려면 명령줄에서 두 번째 인자로 지정합니다.
    패치하기.bat "원본.iso" "D:\Games\스타폭스 어설트 한글.iso"


[원본 이미지]

  게임: 스타폭스 어설트 일본판 (게임 ID GF7J01)

  패처가 게임 파일 하나하나를 원본과 비교하므로,
  덤프 방식에 따라 ISO 전체 MD5가 달라도 게임 파일만 같으면 적용됩니다.
  참고: Redump 정본 ISO는 1,459,978,240 바이트, MD5 27aed37f24061b1ff06cdd3640053481 입니다.
  정본에 적용하면 끝에 「정본(Redump) 원본 기준 결과와 일치합니다」가 나옵니다.

  지원 형식          결과
  ---------------    ------
  ISO, GCM           ISO
  CISO, WIA, WDF,    ISO (동봉한 wit으로 ISO로 바꾼 뒤 적용)
  GCZ
  RVZ                지원 안 함 → Dolphin에서 ISO로 변환한 뒤 적용
                     (게임 우클릭 → 변환 → ISO)
  NKit               지원 안 함 → NKit 도구로 원래 ISO로 되돌린 뒤 적용

  북미판·유럽판, 이미 한글 패치를 적용한 이미지에는 적용되지 않습니다.
  이전 버전 한글판 ISO에 덧씌우는 패치가 아닙니다. 항상 일본판 원본에 적용하세요.


[오류 메시지]

  ~이(가) 아닙니다. 읽은 게임 ID      다른 게임이나 다른 지역판입니다.
  원본의 파일 목록(FST)이 다릅니다    이미 패치한 이미지이거나 다른 판입니다.
  원본 게임 파일이 다릅니다           이미 패치한 이미지이거나 손상된 덤프입니다.
  이미지 크기가 작습니다              잘린 덤프이거나 NKit 이미지입니다.
  RVZ는 지원하지 않습니다             위 [원본 이미지] 표를 참고해 ISO로 바꾸세요.
  ISO로 변환하지 못했습니다           이미지가 손상됐거나 지원하지 않는 형식입니다.


[실행]

  - Dolphin, Wii U vWii + Nintendont, Wii U VC 주입(UWUVCI)에서 확인했습니다.
    게임큐브 실기와 디스크 부팅은 확인하지 않았습니다.
  - 보너스 게임(제비우스 등)을 Dolphin에서 돌릴 때는 그래픽 설정 → 향상 →
    텍스처 필터링을 「기본값」으로 두세요. 니어리스트·리니어로 강제하면 화면이 깨집니다.


[알려진 한계]

  - 스테이지 배경의 간판·전광판, 배틀 모드 결과 표시(COMPLETE, GAME OVER 등),
    무기 이름, 배지 문구는 일본판 원본부터 영문 디자인이라 그대로 두었습니다.
    게임 안 이미지 3,737개를 전수 확인했고, 화면에 나오는 것 중 일본어가 남은 것은 없습니다.
  - 이름 입력은 준비된 음절표(120자) 안에서만 쓸 수 있습니다.
  - 설명 상자의 한 줄짜리 문구는 원래 두 줄 기준 배치라 살짝 아래에 놓입니다.


[업데이트 기록]

  v1.2f (최종판)
    - 무전·컷신 자막 글자 가장자리를 매끄럽게 다듬음(16단계 안티앨리어싱)
    - 무전 화자 이름표 글자 크기를 모든 이름에서 같게 맞춤
    - 무전 창 줄 넘침 29줄 수정(무전 창 실제 폭을 원문에서 재서 검사 기준 교체)
    - 마침표 누락 56줄 보완(줄바꿈 앞 문장 끝 37줄, 대사 끝 감탄사·호칭 19줄)
    - 대사 표현 2줄 수정(시동 → 기동, 「아직이냐고!!」)
    - 메뉴 글씨: 글자 사이 간격을 원본 한자에 맞춰 좁힘, 마침표·쉼표가
      앞 글자에 붙던 문제, 「으」「드」 높이, 받침 없는 「모·스·요」 등 33자 크기 보정
    - 배포 방식을 파일 단위 패처로 변경: 덤프마다 MD5가 달라도 적용,
      CISO·WIA·GCZ 지원, 패치 도구 따로 필요 없음
