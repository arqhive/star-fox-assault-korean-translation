# 대사 검수 가이드 (마침표 · 쉼표 · 직역투)

번역문(`translation/ko/*.json`)을 다듬을 때의 공통 규칙입니다.
원문은 게임 데이터라 저장소에 없으므로, 검수할 때는 ISO 에서 뽑아 둔 `work/src/*.json`(일본어 `jp`, 북미판 `en`)을 참고합니다.

## 공통 제약

- **고치는 파일은 `translation/ko/<파일>.json` 뿐**입니다. `name` 은 절대 바꾸지 않습니다.
- 줄바꿈 `\n` 위치는 그대로 둡니다(대사창 줄 수가 정해져 있음). 한 대사는 최대 3줄.
- 줄 폭 제한: 무전 408px, 데모·무비 자막 504px. 한글 한 글자 22px, 공백 8px, 마침표·쉼표 약 6~8px.
- `{6018:9}`, `{6030:2}` 같은 버튼 아이콘 토큰과 `〈 〉`, `『 』`, `・` 는 그대로 둡니다.
- 한자·가나를 넣지 않습니다(글리프가 없어 빈칸으로 나옵니다).
- 끝나면 `python tools/check_ko.py <파일이름>` 이 **문제 0개**여야 합니다.
- JSON 저장은 `ensure_ascii=False, indent=1`. Bash heredoc 안의 파이썬 문자열에서 `\n` 이 실제 줄바꿈으로 깨지므로,
  스크립트는 Write 도구로 파일에 쓴 뒤 실행하거나 줄바꿈을 `chr(10)` 으로 씁니다.

## 1. 마침표

1. 문장이 끝나는 곳에 `.` 를 찍습니다. 평서문·명령문·청유문 모두.
2. 이미 `?` `!` `…` `~` 로 끝나면 그대로 둡니다. `…` 뒤에 `.` 를 붙이지 않습니다.
3. 다음 대사로 이어지는 줄(조사·연결어미 `~고`, `~해서`, `~라면`, `~지만` 으로 끝남)에는 찍지 않습니다.
   같은 항목 안에서도 줄바꿈 전에 문장이 끝났으면 그 줄 끝에 찍습니다.
4. 문장이 아닌 것에는 찍지 않습니다 — 감탄사(`어이쿠`, `흥`), 호칭만 있는 줄, 명사로 끝나는 보고(`전 기체 귀환`),
   버튼 조작 안내(`{6018:9} 길게`), 미션 부제.
5. 영어판(`en`)의 끝 문장부호가 판단에 도움이 됩니다. 영어판이 `!` 면 `!`, 의문형이면 `?`.
   단 **나우스(020)** 는 담담한 보고체라 `!` 대신 마침표를 씁니다.

## 2. 쉼표 (호격 포함)

1. **부르는 말(호격) 앞뒤**: `고마워 폭스` → `고마워, 폭스` / `폭스 뒤에서 노리고 있다고` → `폭스, 뒤에서…`
   단 줄바꿈으로 이미 갈라져 있으면(`폭스!\n뒤에서…`) 넣지 않습니다.
2. **감탄사·응답어 뒤에 말이 이어질 때**: `좋아 가자` → `좋아, 가자` / `그래 알았다` → `그래, 알았다`
3. **나열**: `폭스 팔코 슬리피` → `폭스, 팔코, 슬리피`
4. **긴 문장의 절 경계**에서 읽기 어려울 때만 (`~고`, `~지만`, `~는데`, `~니까` 뒤). 짧은 문장에는 넣지 않습니다.
5. 일본어 원문의 전각 공백(`　`)이나 `、` 자리가 쉼표 후보라는 강한 단서입니다.
6. 과하게 넣지 않습니다. 줄 끝(줄바꿈 직전)에는 보통 넣지 않습니다.

## 3. 일본어 직역투

고칠 것:

- **대명사 직역**: `그녀`, `그`, `당신` 남발 → 이름·호칭(`너`, `자네`, `녀석`)으로 바꾸거나 생략.
- **`~のだ`/`~ことだ`/`~ものだ` 직역**: `~하는 것이다`, `~라는 것이다` → `~하는 거야`, `~해` 등 구어체로.
- **기계적인 일본식 표현 반복**: `역시`, `과연`, `제대로`, `확실히`, `어떻게든`, `~해 버렸다`, `~하는 중이다`,
  `~할 수밖에 없다`, `~라니`, `~인 거지?` 가 문맥 없이 반복되면 다듬습니다.
- **조사·어순 직역**: `~에 대해`, `~에 있어서`, `~로서의`, 불필요한 `것`, 주어·목적어 과다.
- **감탄사 직역**: `에?`, `헤에`, `훗`, `쿠쿠쿠`, `아레?` → `응?`, `오호`, `흥`, `크크크`, `어라?`
- **말투가 뒤섞인 대사**, 뜻이 통하지 않는 문장.

유지할 것:

- 뜻과 정보(숫자·이름·조작 설명)는 바꾸지 않습니다. 원문 `jp` 로 뜻을 확인합니다.
- 이미 자연스러운 문장은 손대지 않습니다. **과도한 의역·재작성 금지.**
- 캐릭터 말투 설정과 표기(GLOSSARY), 줄 나눔 위치, 버튼 토큰.
