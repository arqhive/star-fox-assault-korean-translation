첫 공개 테스트판입니다. 스토리 대사와 메뉴, 주요 그림 글씨를 한글화했습니다.

**원본 일본판 ISO에 적용하는 패치입니다.**

## 변경 사항

- 스토리: 미션 1에서 10까지의 무전·데모 대사, 무비 자막, 브리핑을 한글화했습니다.
- 메뉴: 싱글·배틀·옵션·결과·메모리카드 메시지를 한글화했습니다. 본체 ROM 폰트를 한글 폰트로 바꿨습니다.
- 그래픽: 미션 부제, 행성 이름, 버튼 라벨, 타이틀 로고 등 96종을 한글화했습니다.
- 이름 입력 화면을 한글 음절표로 바꿨습니다.

## 적용 방법

1. Delta Patcher나 xdelta3로 원본 일본판 ISO에 패치를 적용합니다. xdelta3에서는 다음처럼 실행합니다.

   ```
   xdelta3 -d -s "Star Fox - Assault (Japan).iso" StarFoxAssault_KO_v0.9.xdelta "Star Fox - Assault (Korean).iso"
   ```

2. 결과 파일의 확인값을 아래 표와 비교합니다.
