완성판입니다. 무전·메뉴 글자를 더 읽기 쉽게 다듬고, 줄 넘침과 문장부호를 정리했습니다.

**원본 일본판 이미지에 적용하는 패치입니다.** 이전 한글 패치를 적용한 이미지에는 덧씌울 수 없습니다.

## 변경 사항

- 무전·컷신 자막의 글자 가장자리를 매끄럽게 다듬었습니다.
- 무전 화자 이름표의 글자 크기를 모든 이름에서 같게 맞췄습니다.
- 무전 창에서 넘치던 29줄을 고쳤습니다. 무전 창의 실제 폭을 일본판 원문에서 재서 검사 기준을 바꿨습니다.
- 마침표 누락 56줄을 보완했습니다. 줄바꿈 앞에서 끝나는 문장 37줄, 감탄사·호칭으로 끝나는 대사 19줄입니다.
- 대사 2줄을 다듬었습니다(「기동합니다」, 「센터는 아직이냐고!!」).
- 메뉴·메모리카드·결과 화면 글씨: 글자 사이 간격을 원본 한자에 맞춰 좁히고, 마침표·쉼표가 앞 글자에 붙던 문제와 「으」「드」의 높이를 고쳤습니다. 받침 없는 「모·스·요」 등 33자가 작아 보이던 것도 키웠습니다.
- 배포 방식을 ISO 통째 xdelta에서 파일 단위 패처(`패치하기.bat`)로 바꿨습니다. 덤프마다 ISO 전체 MD5가 달라도 적용되고, CISO·WIA·WDF·GCZ도 받습니다. 별도 패치 도구가 필요 없습니다.

## 배포 파일

| 파일 | 설명 |
|---|---|
| `StarFoxAssault-KO-v1.2f.zip` | 파일 단위 패처(`패치하기.bat`), 사용자 설명서 `README.txt` |
| `SHA256SUMS.txt` | ZIP의 SHA-256 값 |

## 적용 방법

1. ZIP을 풀고, 풀린 폴더에 원본 이미지를 넣습니다.
2. `패치하기.bat`을 더블클릭합니다. 원본 파일을 `패치하기.bat` 위에 끌어다 놓아도 됩니다.
3. 같은 폴더에 `Star Fox Assault (Korean).iso`가 생깁니다.

| 원본 형식 | 결과 |
|---|---|
| ISO, GCM | ISO |
| CISO, WIA, WDF, GCZ | ISO |
| RVZ, NKit | 지원 안 함(ISO로 되돌린 뒤 적용) |
