한글화 그래픽의 배경·테두리·정렬을 다듬은 업데이트입니다. 일본판 영문 타이틀 로고를 유지하면서 아래 일본어 부제만 한글화했습니다. 대사·폰트·실행 코드는 v1.0.1과 같습니다.

**원본 일본판 ISO에 적용하는 전체 패치입니다.** 이전 한글 패치 ISO에 덧씌울 수 없습니다.

## 변경 사항

- 사격·이동·시점 안내의 색 배경을 복원하고 검은 띠와 얼룩을 정리했습니다.
- 핸디캡 입력 상자, 상하 반전 값 상자, 이름 중복 안내의 테두리를 복원했습니다.
- 전적 표시 라벨의 글자 뒤에 남은 배경 얼룩을 없앴습니다.
- 미션 부제·행성명의 공백 간격과 가운데 정렬을 고쳤습니다.
- 상하 반전 설정 화면의 "진동" 글자를 1px 아래로 옮겼습니다.
- 일본판 STAR FOX ASSAULT 영문 로고를 유지하고, 아래 부제를 "스타폭스 어설트"로 한글화했습니다.
- 개발자 빌드에서 북미판 ISO가 없어도 되게 했고, 빠져 있던 capstone 의존성을 추가했습니다.

## 적용 방법

1. Delta Patcher나 xdelta3로 원본 일본판 ISO에 패치를 적용합니다. xdelta3에서는 다음처럼 실행합니다.

   ```
   xdelta3 -d -s "Star Fox - Assault (Japan).iso" StarFoxAssault_KO_v1.1.xdelta "Star Fox - Assault (Korean).iso"
   ```

2. 결과 파일의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README_KO.txt`를 참고하세요.
