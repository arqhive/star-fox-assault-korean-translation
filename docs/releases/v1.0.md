대전(배틀) 모드와 보너스 게임까지 모든 모드를 검수한 정식 버전입니다. 부팅 때 나오는 시스템 메시지도 한글화했습니다.

**원본 일본판 ISO에 적용하는 전체 패치입니다.** 이전 한글 패치 ISO에 덧씌울 수 없습니다.

## 변경 사항

- 대전(배틀) 모드와 보너스 게임의 화면과 문구를 검수해 반영했습니다.
- 부팅 때 나오는 시스템 메시지 16개(프로그레시브 모드 안내, 디스크 오류 등)를 한글화했습니다.
- Wii U VC 주입(UWUVCI)에서 검은 화면이 나오지 않도록 디스크 안 배치를 원본 순서(헤더, 애플로더, DOL, FST, 파일)로 맞췄습니다.
- 배틀 핸디캡 설정값을 "작게"와 "크게"로 한글화했습니다.
- 배틀 룰 설정 화면의 항목 정렬과 글자 주변 얼룩을 정리했습니다.
- 룰 설명 띠의 글자가 왼쪽 아이콘을 덮던 문제를 고쳤습니다.
- 종료 메뉴와 일시정지 메뉴의 글자 크기를 통일했습니다.
- 보너스 게임 조작 설명에서 글자가 상자 밖으로 나가던 문제를 고쳤습니다.
- 무전 화자 이름표에서 받침 ㄹ이 뭉개지던 문제를 개선했습니다.
- 용어를 정리했습니다. "리스타트"는 "재시작", "셀렉트"는 "선택", "어썰트"는 "어설트"로 바꿨습니다.
- 일본어 직역투를 더 정리했습니다.

## 적용 방법

1. Delta Patcher나 xdelta3로 원본 일본판 ISO에 패치를 적용합니다. xdelta3에서는 다음처럼 실행합니다.

   ```
   xdelta3 -d -s "Star Fox - Assault (Japan).iso" StarFoxAssault_KO_v1.0.xdelta "Star Fox - Assault (Korean).iso"
   ```

2. 결과 파일의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README_KO.txt`를 참고하세요.
