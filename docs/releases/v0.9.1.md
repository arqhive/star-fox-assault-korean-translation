대사 검수와 표기 통일, 그림 글씨 정리를 반영한 수정판입니다.

**원본 일본판 ISO에 적용하는 전체 패치입니다.** 이전 한글 패치 ISO에 덧씌울 수 없습니다.

## 변경 사항

- 대사창의 흐린 점과 메뉴 버튼·결과 화면 이미지의 얼룩, 지운 자국을 없앴습니다.
- 화자가 바뀌는 자리에 마침표를, 부르는 말 뒤에 쉼표를 넣었습니다.
- 대사 약 320줄을 원문·영어판과 대조해 일본어 직역투를 다듬었습니다.
- 고유명사를 정식 발매판 표기(안돌프, 카티나, 코네리아, 스타울프, 그레이트폭스, 울펜)로 통일했습니다.
- 메모리카드 확인창의 "예"와 "아니요"를 한글화했습니다.
- 조작 설정 화면의 글자 위치(시점·사격·이동, 진동, 버튼 라벨 간격)를 정리했습니다.

## 적용 방법

1. Delta Patcher나 xdelta3로 원본 일본판 ISO에 패치를 적용합니다. xdelta3에서는 다음처럼 실행합니다.

   ```
   xdelta3 -d -s "Star Fox - Assault (Japan).iso" StarFoxAssault_KO_v0.9.1.xdelta "Star Fox - Assault (Korean).iso"
   ```

2. 결과 파일의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README_KO.txt`를 참고하세요.
