# 변경 내역

## v1.1 — 그래픽 품질 개선 (2026-09-20)

최종 ISO에서 한글화된 텍스처를 원본과 비교해 배경·테두리 손상과 정렬 오류를 수정했습니다. 게임 내 표시 확인을 거친 그래픽 수정본이며, 대사·폰트·실행 코드는 v1.0.1과 동일합니다.

### 그래픽 수정

- 사격·이동·시점 라벨: 원문을 지우면서 생긴 검은 띠와 얼룩을 없애고 색 배경 복원.
- 핸디캡 설정: 검은 입력 상자 상단이 옆으로 튀어나오는 현상 수정.
- 상하 반전 설정: 값 상자의 왼쪽 경계 복원, '진동' 글자를 1px 아래로 조정.
- 이름 중복 안내: 지워진 오른쪽 세로 테두리 복원.
- 전적 표시: 글자 뒤에 남은 배경 얼룩 제거.
- 미션 부제·행성명: 공백 자간의 폭 계산과 실제 배치를 통일해 가운데 정렬 보정. 부제 두 종에서 확인된 −6px 오차는 0px로 수정.
- 타이틀: 일본판 영문 STAR FOX ASSAULT 로고를 유지하고 하단 일본어 부제만 '스타폭스 어설트'로 교체.

### 빌드 도구

- GX RGBA8의 AR/GB 분리 타일 인코딩·디코딩 지원으로 일본판 로고를 직접 편집.
- 로고 빌드에서 북미판 ISO 의존성 제거. 원본 영문 로고는 일본판 ISO에서 읽고, 제작한 한글 부제만 저장소에 포함.
- 단색 라벨 배경을 깨끗한 여백에서 복원하는 `rowcopy` 연산 추가.
- 글자 제거 영역에서 테두리·값 상자를 제외하고 CMPR 압축 블록 경계를 보호.
- 기존 빌드 코드가 사용하지만 요구 사항에서 빠져 있던 `capstone` 추가.

### 검증

- ISO 내 1,090개 파일 빌드 검증 통과.
- v1.0.1 대비 변경은 23개 파일의 텍스처 314개 사본에 한정. 시스템 영역과 텍스처 이외 파일 바이트는 동일.
- 대표 텍스처 97종(로고 포함)을 빌드 ISO에서 다시 추출해 확인.
- 값 상자·아이콘·테두리 보존, RGBA8 왕복 인코딩, 마지막 '진동' 1px 조정의 변경 범위 확인.
- xdelta를 일본판 원본에 적용한 ISO가 게임에서 확인한 최종 빌드와 SHA256 일치.
- 원본과 같은 디스크 크기: 1,459,978,240바이트.
